# 2A Toolbox

2A Toolbox is a secure, easy-to-use web application designed for firearm enthusiasts to manage their collection, track range sessions and cleanings, monitor ammunition inventory, and keep an eye on carry permit expirations. Built with privacy and performance in mind, all data is stored locally in your browser using IndexedDB. This project was developed with assistance from AI tools like [Gab AI](https://gab.ai).

## Features

- **Firearm Inventory:** Catalog your firearms with type, caliber, color, serial number, purchase date and price, condition, optic details, round count, cleaning count, modifications, and notes.
- **Sold Firearm Archive:** Retire a firearm from the active collection without losing its history; sold guns can be hidden from the inventory or shown again at any time.
- **Ammunition Management:** Track ammunition by brand, caliber, and type, with accurate round counts, price, and notes.
- **Smart Ammo Categories:** Calibers are classified automatically into pistol, rifle, shotgun, BB, and airsoft, with a separate customizable low-stock threshold for each category.
- **Range Sessions:** Log your range trips, track round counts, and deduct the ammo used during a session from the matching caliber.
- **Cleaning Log:** Record cleanings per firearm with date, type, and notes; the cleaning page groups sessions across the whole collection and filters by firearm type.
- **Permit Tracking:** Keep concealed carry, possession, non-resident, and other permits in one place, with permit number, issuing authority, issue date, expiration date, and notes.
- **Expiration Notifications:** Permits are marked valid, expiring soon, or expired. Enable expiration notifications and the app will remind you in-app (and via a browser notification if you grant permission) as a permit approaches its expiration date.
- **Dashboard:** Total firearms, shots fired, ammo on hand, recent range sessions, permit status, and more, all in one view.
- **Offline Mode:** Built as a Progressive Web App (PWA); your data stays on your machine, accessible without an internet connection.
- **Data Sovereignty:** Full import/export capabilities; you own your data. No cloud tracking, no logins, no central servers.
- **Responsive Design:** Optimized for both desktop and mobile devices.

## Installation

### Prerequisites

- A modern web browser (Chrome, Firefox, Brave, etc.)

### Local development

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/username/2a-toolbox.git
    ```

2.  **Navigate to the directory:**

    ```bash
    cd 2a-toolbox
    ```

3.  **Serve the application** from the `src` directory:

    ```bash
    python -m http.server 8000 -d src
    ```

    Then open `http://localhost:8000`.

### Building

- **CSS:** `src/styles.css` is generated by concatenating the files in `css-modules/` in this order: `base, layout, navigation, buttons, cards, forms, modals, guns, ammo, ammo-deduction, sessions, stats, import-export, utils, responsive`. Plain concatenation with no separator reproduces the shipped stylesheet exactly.
- **HTML:** `python3 minify-html.py` reads `../src/index.html`, strips comments and whitespace while preserving the GPL license header, and writes `../www/index.html`. Pass `--no-minify` to skip minification.

## Tech Stack

- **Frontend:** Vanilla JavaScript (ES Modules), organized into small modules under `src/modules/`
- **Styling:** Modular CSS in `css-modules/`, concatenated into a single `styles.css`
- **Data Persistence:** IndexedDB (via a custom wrapper)
- **Architecture:** PWA (Service Workers for offline support)
- **Icons:** Font Awesome via CDN

## Privacy & Security

2A Toolbox is built for those who value privacy:

- **No Cloud:** This app is hosted on Cloudflare Pages, but the application stores all user data locally in the browser (IndexedDB/PWA). There is no "back-end."; your data never leaves your device unless you manually export it.
- **No Tracking:** 2A Toolbox does not use analytics, tracking pixels, or remote scripts. The only remote call is for Font Awesome icons via `cdn.jsdelivr.net`, which is handled via https://cdn.jsdelivr.net/npm/@fortawesome/fontawesome-free@6.4.0/css/all.min.css in the source code.
- **No Accounts:** There is no sign-up, login, or synchronization service.
- **Notifications Stay Local:** Permit expiration checks run in the browser; enabling them does not transmit any data.
